# FRC 2026-2027: repositorio de prácticas

Este repositorio se usa para las prácticas y ejercicios del curso de programación FRC del equipo, de cara a la temporada 2027 (Kickoff: 9 de enero de 2027).

Aquí se guardan los ejercicios que se hacen en clase, no el código de competencia del robot. El código del robot vive en su propio repositorio.

## Cómo trabajar

- Cada estudiante trabaja en su propia rama: `sesionN/<nombre>`.
- Los commits siguen el formato convencional (`feat:`, `fix:`, `docs:`, `chore:`).
- Código, commits e identificadores van en inglés.
